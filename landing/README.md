# Suratulem Landing Page

Landing page statis Suratulem — undangan digital, 118 tema, order via WhatsApp ke 081914170701.

## Deploy ke Vercel (cara Aziz)
1. Di Vercel: Add New Project → Import `azizt91/suratulem`
2. Root Directory: `landing`
3. Framework Preset: Other / Static, tanpa build command
4. Deploy. Preview dulu, baru pasang domain `suratulem.my.id` kalau sudah oke.
